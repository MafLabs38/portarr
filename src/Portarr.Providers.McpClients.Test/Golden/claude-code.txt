### install memory | user | linux
supported: yes
requires: MEMORY_MCP_KEY
[command]
  Add the server with Claude Code, at user scope.
    claude mcp add --transport http --scope user memory https://memory.homelab.example/mcp --header 'Accept: application/json' --header 'X-Api-Key: ${MEMORY_MCP_KEY}'
[file] ~/.claude.json
  Merge this into ~/.claude.json; create the file if it does not exist and keep every other entry.
    {
      "mcpServers": {
        "memory": {
          "type": "http",
          "url": "https://memory.homelab.example/mcp",
          "headers": {
            "Accept": "application/json",
            "X-Api-Key": "${MEMORY_MCP_KEY}"
          }
        }
      }
    }

### install github | user | linux
supported: yes
requires: GITHUB_TOKEN
[command]
  Add the server with Claude Code, at user scope.
    claude mcp add --transport stdio --scope user --env 'GITHUB_TOKEN=${GITHUB_TOKEN}' --env 'LOG_LEVEL=info' github -- npx -y @example/github-mcp@1.4.2
[file] ~/.claude.json
  Merge this into ~/.claude.json; create the file if it does not exist and keep every other entry.
    {
      "mcpServers": {
        "github": {
          "command": "npx",
          "args": [
            "-y",
            "@example/github-mcp@1.4.2"
          ],
          "env": {
            "GITHUB_TOKEN": "${GITHUB_TOKEN}",
            "LOG_LEVEL": "info"
          }
        }
      }
    }

requires: MEMORY_MCP_KEY
[command]
  Add the server with Claude Code, at user scope.
    claude mcp add --transport http --scope user memory https://memory.homelab.example/mcp --header 'Accept: application/json' --header 'X-Api-Key: ${MEMORY_MCP_KEY}'
[file] %USERPROFILE%\.claude.json

    {
      "mcpServers": {
        "memory": {
          "type": "http",
          "url": "https://memory.homelab.example/mcp",

            "X-Api-Key": "${MEMORY_MCP_KEY}"
          }
        }

note: Run the commands in PowerShell: they are quoted with single quotes, which cmd.exe does not read as quoting. A value with a character cmd.exe reads is left out of the command: use the file entry.

### remove memory | user | linux
supported: yes
[remove]
  If present, remove the server from Claude Code, at user scope.
    claude mcp remove --scope user memory
[remove] ~/.claude.json
  If present, delete the entry "memory" under mcpServers from ~/.claude.json; touch nothing else.
    the entry "memory" under mcpServers
