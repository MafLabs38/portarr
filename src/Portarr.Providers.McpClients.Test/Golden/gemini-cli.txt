### install memory | user | linux
supported: yes
requires: MEMORY_MCP_KEY
[command]
  Add the server with Gemini CLI, at user scope.
    gemini mcp add --scope user --transport http --header 'Accept: application/json' --header 'X-Api-Key: ${MEMORY_MCP_KEY}' memory https://memory.homelab.example/mcp
[file] ~/.gemini/settings.json
  Merge this into ~/.gemini/settings.json; create the file if it does not exist and keep every other entry.
    {
      "mcpServers": {
        "memory": {
          "httpUrl": "https://memory.homelab.example/mcp",
          "headers": {
            "Accept": "application/json",
            "X-Api-Key": "${MEMORY_MCP_KEY}"
          }
        }
      }
    }
note: Avoid underscores in the server id: Gemini CLI splits tool names on the first one. A stdio server in an untrusted folder shows as disconnected until you run `gemini trust`.

### remove memory | user | linux
supported: yes
[remove]
  If present, remove the server with Gemini CLI, at user scope.
    gemini mcp remove --scope user memory
[remove] ~/.gemini/settings.json
  If present, delete the entry "memory" under mcpServers from ~/.gemini/settings.json; touch nothing else.
    the entry "memory" under mcpServers
