### install memory | user | linux
supported: yes
requires: MEMORY_MCP_KEY
[file] ~/.config/Claude/claude_desktop_config.json
  Merge this into ~/.config/Claude/claude_desktop_config.json; create the file if it does not exist and keep every other entry.
    {
      "mcpServers": {
        "memory": {
          "command": "npx",
          "args": [
            "-y",
            "mcp-remote@0.16.6",
            "https://memory.homelab.example/mcp",
            "--header",
            "Accept:application/json",
            "--header",
            "X-Api-Key:${MEMORY_MCP_KEY}"
          ],
          "env": {
            "MEMORY_MCP_KEY": "<value of MEMORY_MCP_KEY>"
          }
        }
      }
    }
note: Claude Desktop reads no variable inside its file: write the value of each <value of …> placeholder yourself, and keep that file private.
note: A remote server is reached through the mcp-remote bridge (Node.js required); Claude Desktop can also add it as a custom connector in Settings > Connectors.
note: Quit Claude Desktop completely and start it again after editing the file.
