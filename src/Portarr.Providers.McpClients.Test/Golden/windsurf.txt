### install memory | user | linux
supported: yes
requires: MEMORY_MCP_KEY
[file] ~/.config/devin/mcp_config.json
  Merge this into ~/.config/devin/mcp_config.json; create the file if it does not exist and keep every other entry.
    {
      "mcpServers": {
        "memory": {
          "serverUrl": "https://memory.homelab.example/mcp",
          "headers": {
            "Accept": "application/json",
            "X-Api-Key": "${env:MEMORY_MCP_KEY}"
          }
        }
      }
    }
note: Older Windsurf builds read ~/.codeium/windsurf/mcp_config.json instead; use the file your installed version opens from its MCP settings.
