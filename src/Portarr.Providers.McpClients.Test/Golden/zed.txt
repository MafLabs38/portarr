### install memory | user | linux
supported: yes
requires: MEMORY_MCP_KEY
[file] ~/.config/zed/settings.json
  Merge this into ~/.config/zed/settings.json; create the file if it does not exist and keep every other entry.
    {
      "context_servers": {
        "memory": {
          "url": "https://memory.homelab.example/mcp",
          "headers": {
            "Accept": "application/json",
            "X-Api-Key": "<value of MEMORY_MCP_KEY>"
          }
        }
      }
    }
note: Zed reads no variable inside its file: write the value of each <value of …> placeholder yourself, and keep that file private.
note: Open the file with the action "zed: open settings file"; its location above is the usual one (not verified on every system).
