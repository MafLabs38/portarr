### install memory | user | linux
supported: yes
requires: MEMORY_MCP_KEY
[command]
  Add the server to the user profile with the code command.
    code --add-mcp '{"name":"memory","type":"http","url":"https://memory.homelab.example/mcp","headers":{"Accept":"application/json","X-Api-Key":"${env:MEMORY_MCP_KEY}"}}'
[file] ~/.config/Code/User/mcp.json
  Merge this into ~/.config/Code/User/mcp.json; create the file if it does not exist and keep every other entry.
    {
      "servers": {
        "memory": {
          "type": "http",
          "url": "https://memory.homelab.example/mcp",
          "headers": {
            "Accept": "application/json",
            "X-Api-Key": "${env:MEMORY_MCP_KEY}"
          }
        }
      }
    }
note: The path of the user file is the usual one: "MCP: Open User Configuration" in VS Code opens the right file. VS Code asks to trust a server the first time it starts.

### install github | user | linux
supported: yes
requires: GITHUB_TOKEN
[command]
  Add the server to the user profile with the code command.
    code --add-mcp '{"name":"github","type":"stdio","command":"npx","args":["-y","@example/github-mcp@1.4.2"],"env":{"GITHUB_TOKEN":"${env:GITHUB_TOKEN}","LOG_LEVEL":"info"}}'
[file] ~/.config/Code/User/mcp.json
  Merge this into ~/.config/Code/User/mcp.json; create the file if it does not exist and keep every other entry.
    {
      "servers": {
        "github": {
          "type": "stdio",
          "command": "npx",
          "args": [
            "-y",
            "@example/github-mcp@1.4.2"
          ],
          "env": {
            "GITHUB_TOKEN": "${env:GITHUB_TOKEN}",
            "LOG_LEVEL": "info"
          }
        }
      }
    }
note: The path of the user file is the usual one: "MCP: Open User Configuration" in VS Code opens the right file. VS Code asks to trust a server the first time it starts.
