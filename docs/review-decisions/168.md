# Review decisions: PR #168

Answers to the findings of the five review agents on the first head (8d8b8a4): R-168-1 to 17. The maintainer decided the model in the conversation that led to the second head: no approval step, the role decides (Admin writes, Operator reads and changes nothing, how a host is reached needs `settings.manage`).

## R-168-1 | security | high | fixed

- **Finding**: With the approval gone, nothing controls an MCP server's `stdio`, a command the workstations run.
- **Where**: CatalogEditor.cs, ProtectedSettings.cs
- **Reason**: `stdio` is a protected setting: only a role holding `settings.manage` writes it, any other is refused (403). The Operator no longer holds `catalog.write` at all.

## R-168-2 | security | high | fixed

- **Finding**: The Operator role and the shared keys gain the power to point a connector, and its credential, at another host.
- **Where**: Permissions.cs (BuiltInRoles), CatalogEditor.cs, CatalogEditController.cs, CatalogTools.cs
- **Reason**: `catalog.write` leaves the Operator role; changing how a host is reached, or removing an item that holds such a setting, needs `settings.manage` and is refused otherwise, for the API, the MCP tools and the chat alike. Integration tests cover the shared key refused and an Admin's personal key written.

## R-168-3 | security | medium | fixed

- **Finding**: Removing an item that holds a connection now happens at once for anyone.
- **Where**: CatalogEditor.cs
- **Reason**: Removing such an item follows the same role rule (unit test).

## R-168-4 | security | low | fixed

- **Finding**: R-144-49 and R-144-104 were declined because of the approval.
- **Where**: docs/review-decisions/144.md
- **Reason**: The control they relied on is now the role: the `http` and `stdio` of a server, and other host names, are written only by a role holding `settings.manage`.

## R-168-5 | architecture | major | fixed

- **Finding**: The permission boundary of D-123 went with the queue.
- **Where**: as R-168-2
- **Reason**: Kept as a permission, not a queue: `settings.manage` for connections, and the Operator reads only. ADR 0026 names the Operator role and the shared keys.

## R-168-6 | architecture | major | fixed

- **Where**: CatalogEditor.GetItemAsync, CatalogTools.get_catalog_item
